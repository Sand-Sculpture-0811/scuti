# 川大人格图鉴 · 第二版

React + TypeScript + Vite 静态网站。48道修订行为题、16个人格、16张原创纸模小人插画、中英双语结果和海报。无后端，无答题数据上传。非官方娱乐测试，试验性评分，不声明心理学效度。

## 本版变化
- 32道初版扩展并重写为48道行为题，每类3条直接证据（2条正向、1条反向），固定打乱顺序。
- 交换人生者 Exchanger 指“考虑或联系别人代课，让自己去做想做的事”，不再代表交换留学。
- 场景区分课堂犯困/主动熬夜、出门卡点/任务拖延、即时小吃/探索新店、单独陪伴/主动拓展关系、旅行/代课。少量共享行为仅加弱权重，具体依据保存在每题 rationale。
- 保留原始16种中英文名称；结果每次显示一个主导人格，不出现“暂难区分”。同分时先比较直接行为得分，再按固定顺序决胜，并显示简短说明。
- 全新响应式图鉴、人物筛选及详情、专属结果文案、48题进度恢复、键盘1–5选择、重测确认、分享海报。
- 旧32题进度不会误读为新48题答案；本地存储使用独立版本键。

## 本地运行
需要 Node.js 22。
```sh
npm ci
npm run dev
npm test
npm run build
```

## 部署到 scuti（手动上传静态文件）
```sh
npm run build -- --base=/scuti/
```
将 dist 内的 index.html、assets 文件夹、characters 文件夹上传到仓库根目录。
GitHub Pages 选择 Deploy from a branch → main → /(root)。
用户收到的“直接上传版.zip”已经按 /scuti/ 构建；先解压再上传，不要把ZIP本身当网页上传。
如仓库已有旧 assets 文件，可以暂时保留，新的 index.html 会引用新版文件。

## 源码仓库自动部署
将源码放在仓库根目录。Settings → Pages 选择 GitHub Actions。
.github/workflows/pages.yml 会执行 npm ci、npm test、构建、上传与部署。
不要把“源码版”和“直接上传版”混作同一套部署方式。

## 计分
题目有符号权重 → 答案中心化 (x-3)/2 → 每类除以其绝对权重之和 → 温度0.25、减最大值的稳定softmax。
反向题的符号已在权重中，只反向一次。百分比用最大余数法，整数总和100。前三直接使用16类原始占比，不重新归一化。
直接证据权重为±2，少量明确的共享行为权重为±0.25或0.5。每题含primary、reverse、weights及rationale，支持后续真实样本校准。
全同项与部分正反向冲突只给解释，不偷偷丢弃或修改答案。低频或未经历不等于道德评价。

## 验证与限制
npm test 生成 validation.json，含16类严格获胜的完整答卷、原始分数与领先值、题目矩阵哈希，以及固定种子10000份均匀随机答卷的胜出分布和领先值分位数。
自动测试覆盖矩阵与直接证据数、可达性、总和、有限值、全选同项、相反答案、交替极值、缺答、非法值、重复修改、反向题、稳定并列与交换人生者语义。
这些检查证明算法实现与可达性，不证明心理学准确率，也不保证真实人群类别均衡。48题文案仍应做自愿试测与反馈校准。
新版通过构建及评分自动测试；已查看首页初步预览，但最终手机布局和海报下载未完成端到端浏览器验证（浏览器工具连接失败）。

## 插画
16个人物使用内置 image_gen 生成，以用户认可的几何纸模小人样稿统一风格；不同性别、发型、服装与道具。public/characters 内为JPEG网页资源，原始PNG和生成提示词另附插画包。无第三方字体或分析脚本。人物外观不参与计分。
